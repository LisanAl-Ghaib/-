# Auto Conversion MVP

This project aims to build a minimal viable product that automatically converts legacy PHP projects to Node.js with Express. The MVP will demonstrate that such conversion is possible and largely automated while keeping most of the original site functionality.

## Repository Structure

- `src/` – source code for the converter tool
- `test_data/` – sample PHP projects used for testing
- `PLAN.md` – step-by-step development plan

See `PLAN.md` for the current implementation roadmap.
