# Дом

Пиксельная многоэтажка в разрезе — «живой аквариум». В доме живут жильцы, которых
придумывает автор: они ходят на работу, гуляют во дворе, готовят, ходят друг к другу в гости,
ссорятся и мирятся. Вокруг дома сменяются день и ночь, погода и времена года.

```bash
npm install
npm run dev        # открыть http://localhost:5173
```

* Колёсико — масштаб, перетаскивание — панорама, клик по квартире — заглянуть внутрь,
  клик по жильцу — карточка. Пробел — пауза, `1`–`4` — скорость (⏸, ×1, ×10, ×60).
* Мир сохраняется в браузере (IndexedDB) и продолжает жить с того же места.
  `?fresh=1` — начать заново, `?seed=42` — свой seed, `?nosave=1` — без сохранения.

Жильцы и квартиры описаны в `data/` (JSON, проверяется `npm run validate`).
Как добавить жильца — в `CLAUDE.md`, архитектура — в `docs/ARCHITECTURE.md`.
