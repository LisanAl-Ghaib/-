# Спрайты: процедурные и свои PNG

Вся графика сейчас рисуется кодом (`src/render/sprites/`). Любой спрайт можно заменить своим
PNG без изменения кода: положите файл в `public/sprites/` и пропишите его в
`public/sprites/manifest.json`:

```json
{
  "overrides": {
    "resident:olga": "residents/olga.png",
    "furniture:sofa": "furniture/sofa.png"
  }
}
```

## Жилец — `resident:<id>`

Лист кадров 12 × (24×24 px) в один ряд, персонаж смотрит **вправо**, стоит по центру ячейки
(x = 12), ступни — на нижней строке (y = 23). Порядок кадров (`FRAME` в
`src/render/sprites/character.ts`):

| № | кадр | № | кадр |
|---|------|---|------|
| 0 | стоит (профиль) | 6 | стоит лицом к зрителю |
| 1–4 | шаг (цикл) | 7 | сидит лицом к зрителю |
| 5 | сидит (профиль) | 8 | лежит (голова справа, нижние 5 строк) |
| 9 | говорит (лицом, жест) | 10 | работает руками (профиль) |
| 11 | машет рукой | | |

Вариант в пальто для холода — ключ `resident:<id>:coat` (та же раскладка).

## Мебель — `furniture:<id>`

Один кадр размером ровно `w × h` из каталога (`data/catalog/furniture.json`), предмет
нарисован «как стоит у стены», без отражения: зеркалирование делает движок (`flip`).
Точки использования (`slots`) берутся из каталога, так что при замене картинки
поведение жильцов не меняется.

Все PNG рисуются без сглаживания; используйте целые пиксели и прозрачный фон.
