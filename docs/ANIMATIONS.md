# Анимации жильцов

Каждое долгое занятие жильца — маленькая живая сценка. Сценки устроены в два слоя:

1. **База** (`src/render/anim/library.ts`) — одна стандартная сцена на каждое занятие в каждом
   месте. Она **одинакова для всех** жильцов: поза, ракурс, вещи в руках, такты, мелкие движения.
2. **Личное** (`src/render/anim/personal.ts`) — манеры конкретного человека. Они **только
   добавляют** к базе и не меняют общую схему.

Движок (`src/render/animation.ts`) собирает позу из базы и личных добавок, а сверху кладёт общие
для всех слои: жест из окна, одевание в прихожей, разговор, дыхание и моргание.

Посмотреть все сцены вживую: `npm run dev` → `http://localhost:5173/?atlas=1`. Это **атлас**:
строка — одна базовая сцена, столбец — один жилец со своими манерами.
`?atlas=read,wash` — только эти занятия. Снимок общих занятий: [atlas-common.png](atlas-common.png).

## Как устроена сцена

```
занятие × место → сцена { поза, базовый ракурс, такты | сценарий, мелкие движения }
```

* **Место** (`Place`) берётся из предмета мебели (`src/render/anim/place.ts`): `bed`, `bath`,
  `shower`, `basin`, `toilet`, `table`, `desk`, `seat`, `recliner`, `stove`, `sink`, `fridge`,
  `window`, `plant`, `aquarium`, `piano`, `amp`, `bar`, `mat`, `bike`, `easel`, `outdoor`, `floor`.
  Читать в кровати, в кресле и за столом — три разные сцены, но в кресле все читают одинаково.
* **Такты** (`Beat`): каждые ~5 игровых минут выбирается следующий такт (с весом `w`):
  жест (`rest`, `slouch`, `hands`, `handUp`, `cross` сидя; `stand`, `work`, `workUp`,
  `phoneStand`, `talk`, `wave` стоя), ракурс (`front`/`side`/`back`), вещь в руках и быстрое
  чередование `alt` (печатает, мешает, жуёт).
* **Сценарий** (`script`): процедурный цикл там, где тактов мало — сон, душ, курение, турник,
  пианино, электрогитара, реклайнер.
* **Мелкие движения** (`Micro`): каждые ~2,6 с — повернул голову, почесал затылок, ссутулился,
  поёрзал, обернулся, потянулся. Сцена задаёт, какие из них уместны (у плиты руки заняты —
  только обернуться и переступить).
* Что рендер рисует поверх: `cover` — одеяло целиком или до пояса, вода в ванне; `hidden: 'door'` —
  закрытая дверь туалета со светом над ней; `glass` — силуэт за стеклом душа.

## Общие занятия

Сцены, которые делают все жильцы, — в каждом месте одинаково.

| Занятие | Где | Как выглядит |
|---|---|---|
| **Сон** | кровать | лежит под одеялом, одеяло поднимается от дыхания, раз в ~20 мин переворачивается на другой бок; над головой «zzz» |
| | сидя | уснул сидя: ссутулился, голова опущена |
| **Дрёма днём** | кровать | лёг поверх постели, укрыт по пояс, дышит |
| | сидя | клюёт носом, иногда вскидывает голову |
| **Кошмар** | кровать | сидит в кровати лицом к нам, часто дышит, трёт лицо руками |
| **Туалет** | туалет | дверь закрыта, в окошке над дверью свет; самого не видно |
| **Душ** | душевая | за запотевшим стеклом силуэт: стоит под струёй, поднимает руки (моет голову), поворачивается спиной; одежда на дверце, идёт пар |
| **Ванна** | ванна | лежит в воде по плечи, по воде бегут пузырьки, иногда приподнимается |
| **Умывание** | раковина | спиной к нам: чистит зубы (щётка ходит у рта), умывается пригоршнями, вытирается полотенцем, смотрит в зеркало |
| **Еда** | за столом | вилка ко рту и обратно, жуёт, отпивает из чашки; сидит боком или спиной к нам |
| | на диване | тарелка на коленях |
| | в реклайнере | развалившись, вилка ко рту |
| **Чай/кофе** | за столом | держит чашку, отпивает, ставит; листает газету |
| **Перекус** | холодильник | открыл дверцу и заглядывает (спиной), достаёт, жуёт на ходу |
| **Готовка** | плита | спиной/боком: мешает ложкой, режет ножом, пробует с ложки, ждёт, глядя в кастрюлю |
| **Мытьё посуды** | мойка | трёт тарелку губкой, ополаскивает, ставит в сушилку |
| **Разобрать покупки** | кухня | достаёт из пакета, раскладывает в холодильник и по полкам |
| **Заправить кровать** | у кровати | встряхивает одеяло, разглаживает, взбивает подушку |
| **Прибраться** | комната | протирает тряпкой полки, складывает одежду |
| **Вынести мусор** | — | пакет в руке (рисуется поверх ходьбы) |
| **Чтение** | кровать | лёжа под одеялом по пояс: книга над лицом, иногда опускает её на грудь, перелистывает |
| | кресло/диван | книга в руках, перелистывает; опускает на колени и задумывается; отпивает чай |
| | за столом | боком к нам: книга на столе, пометки ручкой, подпирает голову |
| **Телевизор** | диван/кресло | боком, лицом к экрану: пульт, откидывается, нога на ногу, отпивает, заглядывает в телефон |
| **Телефон** | сидя/стоя | трубка у уха, жестикулирует свободной рукой; или листает экран |
| **Компьютер, работа** | стол | боком: печатает, водит мышкой, откидывается, пишет ручкой, говорит по телефону |
| **Окно** | окно | смотрит на улицу спиной к нам, иногда оборачивается в комнату |
| **Цветы** | цветок/подоконник | поливает из лейки, наклоняется к земле |
| **Просто сидит/стоит** | — | откинулся, нога на ногу, телефон, чашка; стоя — оглядывается, потягивается |
| **В гостях, с гостями** | — | сидит, разговаривает, жестикулирует (книгу и телефон в разговоре не берёт) |
| **Лавочка** | двор | лицом к нам: сидит, нога на ногу, газета, телефон |
| **Курение** | у подъезда / в окно | сигарета у груди → затяжка (рука ко рту, кончик ярче) → выдох облачком; в окно — чаще спиной |
| **Доска** | грифельная доска | спиной к нам: пишет мелом, отступает посмотреть, дописывает список дел, рисует кота |
| **Кружок** | стол с доской | двигает фигуру, объясняет, слушает детей; дети сидят вокруг |
| **Одевание** | прихожая | снимает куртку с вешалки, руки в рукава, нагибается к шнуркам, поправляет воротник |

Занятия по увлечениям (пианино, гитара, турник, рукоделие, шахматы, игры, рыбка) устроены так же:
одна сцена на место, одинаковая для всех, у кого это увлечение есть. Полный список с описаниями —
в атласе (`?atlas=1`); каждое описание — поле `note` сцены.

### Что было не так и исправлено

* **Чтение в кровати** выглядело как сон (просто лежит). Теперь книга над лицом, одеяло по пояс.
* **Умывание у раковины** брало губку для посуды. Теперь зубная щётка, умывание, полотенце, зеркало.
* **Дрёма на кровати** не отличалась от ночного сна — теперь укрыт только по пояс.
* **Готовка** — добавлены нарезка ножом и проба с ложки; **мойка** — тарелка в руках;
  **еда на диване** — тарелка на коленях; **перекус** — еда в руке; **покупки** — пакет;
  **уборка** — складывает одежду.
* Сидя в кресле лицом к нам, человек подолгу «поворачивался боком» и вылезал за спинку —
  такой такт убран (короткий поворот головы остался).
* Душ, туалет, одеяло и вода раньше решались в рендере по id действия, теперь — в сцене библиотеки
  (`glass`, `hidden`, `cover`), как и всё остальное.

## Личный слой

Манера — небольшая добавка к общим сценам. Каталог (`MANNERISMS` в `src/data/schemas.ts`):

| Манера | Что добавляет | Выводится сама из |
|---|---|---|
| `fidgety` | темп ×1.25, чаще ёрзает и оглядывается | `activity: active` |
| `unhurried` | темп ×0.8, реже мелкие движения, лишний такт «откинулся» | `activity: lazy` |
| `adjusts_glasses` | поправляет очки | очки в `accessories` |
| `adjusts_shawl` | запахивает шаль | шаль |
| `strokes_beard` | трёт бороду, думая за компьютером и шахматами | борода |
| `embroiders` | в рукоделии пяльцы с иглой вместо спиц | привычка `crafts` с «вышивает» |
| `coffee_lover` | за чтением и работой чаще с чашкой | тег про кофе |
| `phone_in_hand` | в свободную минуту — в телефон | только явно |
| `cross_legged` | чаще сидит нога на ногу | только явно |
| `pencil_tap` | думая, постукивает карандашом по подбородку (чтение, работа, шахматы, кружок) | только явно |
| `draws_in_air` | объясняя, рисует руками схемы в воздухе | только явно |
| `notebook` | блокнот в руках; после разговора записывает — стоя, сидя и на ходу | только явно |
| `reads_everywhere` | с книгой и на лавочке, и в кресле, и у окна | только явно |
| `sore_back` | спина ноет: потягивается, откидывается | только явно |
| `tilts_head` | слушает, повернувшись к собеседнику и кивая | только явно |

Сейчас у жильцов (всё выведено из уже описанного):
**Иван** — непоседа, кофе; **Ольга Дмитриевна** — очки, шаль, вышивка;
**Павел** — неспешный, борода; **Снежана** — непоседа, очки, кофе;
**Клод Антропович** — неспешный, карандаш у подбородка, схемы в воздухе, блокнот, книга везде,
больная спина, слушает, наклонив голову (явно в его JSON — так описал пользователь).

Явно манеру можно дописать в `data/residents/<id>.json`: `"mannerisms": ["cross_legged"]`.

### Гарантии

* Личный слой может: добавить такты (той же позы и тех же ракурсов, что у базы), заменить вещь
  на похожую (`SWAPPABLE`), сдвинуть темп в пределах 0.75…1.3, добавить мелкие движения.
* Не может: убрать базовые такты, поменять позу или ракурс сцены, заменить сценарий.
  Движок отбрасывает добавки, которые выходят за рамки сцены.
* `tests/animation.test.ts` проверяет: у каждого действия есть базовая сцена; база у всех
  жильцов остаётся первой и целиком; добавки не выходят за позу и ракурсы; кадры позы всегда
  из рамок базы.

## Как добавить

* **Новое действие** → сцена в `LIBRARY` (иначе тест упадёт), значок в `icons.ts` и
  `iconFor` (`renderer.ts`), строчка в таблицу выше. Проверить в атласе.
* **Новое место** → `Place` в `anim/types.ts`, предмет в `anim/place.ts`, сцена в библиотеке.
* **Новая вещь в руках** → `PropKind` и рисовалка в `src/render/props.ts`.
* **Особенность жильца** («крутит ручку, когда думает») → манера в `MANNERISMS` и `APPLY`
  (`personal.ts`); если её можно вывести из описания — в `autoMannerisms`.
