# «Дом» — заметки для Claude

Пиксельная многоэтажка в разрезе, «живой аквариум»: жильцы (их придумывает пользователь)
живут своей жизнью — работают, готовят, гуляют, ходят в гости, ссорятся и мирятся.
Вокруг дома меняются время суток, погода и времена года. Цели у игры нет.

## Главные принципы (от пользователя)

0. **У мира нет настроек.** Пользователь ничего в нём не меняет: нет паузы, ускорения,
   «нового мира», карточек и списков жильцов. Время идёт само (1 реальная минута =
   1 игровой час) и не останавливается, пока страница закрыта: при возвращении пропущенное
   досчитывается (до 30 игровых дней). Можно только смотреть: двигать камеру, приближать,
   заглядывать в квартиры, проследить за человеком, читать хронику.
   **Кто где живёт и сколько лет** — только на стенде «Жильцы дома» у почтовых ящиков на
   первом этаже (клик по стенду). Больше нигде (ни подписей над головами, ни панелей).
   **Характер узнаётся по поступкам.** Описание жильца (черты, привычки, работа) — только
   «двигатель» поведения в данных, на экране его нет. Хроника пишется с позиции соседа:
   что видно и слышно, без мыслей и мотивов. Внутренние события (болезнь, праздник)
   попадают в хронику, когда их можно заметить (`chronicleAt`).
   **У каждого долгого занятия — мини-анимация**: смена поз, вещи в руках, экраны
   (`docs/ANIMATIONS.md`). **Анимации в два слоя:** база — `src/render/anim/library.ts`,
   одна стандартная сцена на «занятие × место» (читать в кровати / в кресле / за столом),
   одинаковая для всех жильцов; личное — `src/render/anim/personal.ts`, манеры (`mannerisms`
   в JSON жильца или выводятся сами: очки, борода, «гиперактивный»…), которые только добавляют
   такты, похожие вещи и темп и не меняют позу и ракурсы базы. Новое действие — сцена в `LIBRARY`
   (тест проверит) с ракурсом (`o`: лицом / боком / спиной — у плиты, мойки,
   окна и за столом люди стоят и сидят спиной, у телевизора — боком к нему). Поверх поз
   всегда идут мелкие движения: дышат, моргают, оглядываются, поправляют очки, ёрзают.
   Все сцены вживую — атлас `?atlas=1` (`src/dev/atlas.ts`).
   Вещи тоже живут (`drawAmbient`/`drawGlow` в `renderer.ts`): часы показывают игровое время,
   радио играет, обогреватель щёлкает, телевизор мерцает в темноте, в солнечных лучах пылинки.
   Экраны разные (`screens.ts`: каналы, сериалы, игры, работа, сайты, дискорд — меняются
   по ходу) и подсвечивают тёмную комнату своим цветом. Над человеком — значок занятия
   в белой плашке (`iconFor` в `renderer.ts`; новому действию — свой значок в `icons.ts`),
   а у того, за кем следят, внизу подпись «Иван: подтягивается на турнике».
1. **Никаких цифр о людях в интерфейсе.** Потребности, характер, настроение, симпатии у
   жильцов есть в симуляции, но пользователь их НЕ видит. Он видит только проявления:
   что человек делает, где он, следы в квартире (посуда, незаправленная кровать, пакеты,
   мусор), значки над головой (зевает, вздыхает, напевает), хронику событий. Не добавлять
   в UI шкалы, проценты, «настроение: 70» и т. п.
2. **Акцент — на людях и их жилье.** Квартиры должны быть подробными и «обжитыми»:
   больше мебели и мелочей, следы быта, которые меняются от жизни жильцов.
3. **Быт общий для всех жильцов.** Каждый ходит в туалет (потребность `bladder`, дверь
   закрывается), сразу разбирает сумки из магазина в холодильник, готовит, моет посуду,
   выносит мусор. Куртку надевают в прихожей у вешалки и снимают там же (`src/sim/dressing.ts`,
   флаг `dressed`), в душе за запотевшим стеклом виден только силуэт, одежда — на дверце.
   Читают те, у кого привычка `reading`, а почитать может любой, у кого дома есть книги
   (стеллаж, стопка книг, полка). Звонят только тем, с кем созваниваются (`contacts.phone`).
   Днём прилечь — на кровать; перед сном не дремлют.
   Новое бытовое действие должно работать для любого жильца, а не для одного.
4. **Дом растёт вместе с жильцами.** 1 этаж — подъезд (слева комната консьержки Ольги
   Дмитриевны Шпак, справа колясочная/велосипеды/почта/выход во двор); 2 этаж — слева квартира
   Павла Мурова (холостяцкая, почти пустая), справа студенты Иван Муравьев и Снежана Галимова; 3 этаж достроен
   (`building.construction.finished` в `data/world.json` — пользователь сказал «стройка закончена»: этаж сдают сразу,
   бригада уходит): справа Клод Антропович Опусов с котом Токеном (книги до потолка, грифельная доска,
   старое пианино, по субботам шахматный кружок для детей), слева пустая квартира. Стройка нового этажа
   (`building.construction` без `finished`) идёт ~30 рабочих дней бригады — колонны, кладка, кран, перекрытие,
   окна, штукатурка. Новый этаж без стройки появляется сам, когда описана квартира на нём.
   **У каждой квартиры выше первого этажа — балкон** в торцевой стене (у левых — слева, у правых —
   справа; `apt.balcony` в `layout.ts`, `BALCONY_D`): дверь в стене, перила, вещи хозяев
   (`balcony.items` в JSON квартиры: цветы, стул, сушилка с бельём, коробки, лыжи…). Любой жилец выходит
   туда подышать, с чаем, полить цветы, развесить бельё, почитать (действие `balcony`, в мороз — на минутку);
   соседи с балконов разных этажей переговариваются.
5. **Экран без пустот и краёв мира.** Над домом — высокое небо (облака, птицы, самолёт ночью),
   под ним — подвал и разрез земли (`SKY_MARGIN`, `GROUND_H` в `src/config.ts`). Камера не даёт
   отдалиться так, чтобы стал виден край мира (`Camera.minZoom`); «⌂ Дом» — весь дом крупно.
   Если меняешь геометрию мира — координаты в старом сохранении сдвигаются сами (`shiftGeometry`).

Подробная архитектура — `docs/ARCHITECTURE.md`. Спрайты и их подмена — `docs/SPRITES.md`.

## Команды

```bash
npm install
npm run dev          # http://localhost:5173  (?fresh=1 — новый мир, ?seed=42 — свой seed, ?nosave=1 — без сохранения, ?atlas=1 — атлас анимаций)
npm run validate     # zod-валидация всех JSON + перекрёстные проверки (ОБЯЗАТЕЛЬНО после правки data/)
npm run sim -- --days 3 --seed 42   # безголовая симуляция, печатает хронику (--fixtures — тестовый дом)
npm test             # vitest: RNG, детерминизм, схемы, поведение
npm run build        # typecheck + production-сборка
npx tsx scripts/weather-check.ts   # статистика прогулок по погоде за 120 дней
npm run build:artifact   # всё в один файл dist-artifact/dom.html (для страницы на claude.ai / телефона)
```

Версия для телефона опубликована как страница: https://claude.ai/artifact/PjD8V56jUKJeJXHtVD1Xfo (обновлять публикацией того же файла).
После изменений: `npm run build:artifact` и опубликовать `dist-artifact/dom.html` в ту же страницу.

В браузере в консоли доступен `dom` (`dom.sim`, `dom.defs`, `dom.renderer`, `dom.host`):
например, `dom.sim.run(8640)` — прокрутить сутки.

## Стек и структура

Vite + TypeScript + Canvas 2D (обоснование — в ARCHITECTURE.md), zod, IndexedDB.

```
data/
  world.json               seed, дата старта, параметры дома
  catalog/furniture.json   каталог мебели (размеры, слоты использования, вид отрисовки)
  residents/<id>.json      один файл = один жилец (имя файла = id)
  apartments/<id>.json     одна квартира (id = apt-<этаж>-<left|right>, этаж по-человечески:
                           1 — первый; apt-1-left — комната консьержки, apt-1-right не бывает)
src/
  core/      RNG (sfc32, сохраняемое состояние), календарь, шина событий, математика
  data/      zod-схемы, сборка WorldDefs, загрузчики (браузер / Node)
  world/     геометрия дома, навигация, лифт
  sim/       состояние мира, шаг симуляции, потребности, распорядок, ИИ-действия,
             отношения, взаимодействия, события, погода, хроника и нарратор
  render/    рендер в буфер мира + целочисленное масштабирование, процедурные спрайты
  ui/        DOM-панели: время, хроника, карточка жильца, квартира
  persist/   IndexedDB-сохранение
scripts/     validate.ts, sim.ts
tests/       vitest; tests/fixtures/data — тестовый дом с пятью жильцами (не трогать data/ ради тестов)
public/sprites/manifest.json   подмена процедурных спрайтов на PNG
```

## Железные правила кода

1. **Детерминизм.** В `src/sim/`, `src/world/`, `src/core/` нельзя `Math.random()`,
   `Date.now()`, `performance.now()`, `new Date()` без аргументов. Только `world.rng`
   (seeded) и игровое время `state.time`. Рендер для косметики использует свой RNG.
2. **Данные отдельно от кода.** Никаких жильцов/квартир в TS. Всё — в `data/`, через zod.
3. **Состояние сериализуемо.** `WorldState` — только JSON-совместимые данные
   (никаких классов, Map, функций). Статика (`WorldDefs`) в сохранение не попадает.
4. **Расширяемость событий.** Новое событие — новый файл в `src/sim/events/defs/`
   и строка в `src/sim/events/index.ts`. Текст — через `Narrator`, не в логике.
5. Пиксель-арт: все координаты отрисовки в буфере мира — целые числа.
6. При изменении формы `WorldState` — увеличить `SAVE_VERSION` в `src/sim/state.ts` и, если
   старое сохранение можно дополнить (новые поля заполняются `??=` в конструкторе `Simulation`),
   добавить прежнюю версию в `MIGRATABLE_VERSIONS` — тогда мир пользователя не начнётся заново.

## Добавление жильца по описанию пользователя

Пользователь описывает нового персонажа обычным текстом в чате (подсказка для него —
`docs/RESIDENT_CHECKLIST.md`). Получив описание, пройди по чек-листу пункт за пунктом:
каждую деталь описания нужно воплотить — в данных, в интерьере или, если движок этого
ещё не умеет, доработкой движка (так появились кошки, гости-родня, бессонница,
вечно включённый телевизор). Не теряй ни одной детали. Дальше:

1. **Создай `data/residents/<id>.json`** по схеме `ResidentSchema` (`src/data/schemas.ts`).
   `id` — латиницей, коротко (`olga`, `vera-pavlovna`). Обязательные части:
   * `name` — имя, фамилия, (отчество), `short`, `kids` (как зовут дети: «дядя Клод»), и **падежи** `cases` (gen/dat/acc/ins/pre) —
     хроника пишет «зашла к Марку», «поссорилась с Ольгой», поэтому падежи заполняй вручную
     и правильно;
   * `gender` (`m`/`f`), `birthday` (`YYYY-MM-DD`, возраст считается от игровой даты);
   * `occupation` — `kind` (office / shift / remote / freelance / student / school / retired /
     unemployed / homemaker / onsite — работает прямо в доме, как консьержка), `title`,
     `workplace`, `schedule` (`days` 1=пн…7=вс, `start`,
     `end`; ночная смена — `end` меньше `start`), `commuteMinutes`, `commute` (bus/walk),
     `sideJob` — подработка из дома параллельно (`days`, `hours` в день): студент работает онлайн;
   * `traits` — `chronotype` (lark/neutral/owl), `sociability` (homebody/balanced/outgoing),
     `temper` (calm/even/hot), `outlook` (gloomy/neutral/cheerful), `activity`
     (lazy/normal/active), `tags` — свободные черты словами; `sleep` (`wake`/`bed`) — свой режим сна,
     если пользователь назвал часы («встаёт в 6:30, ложится около полуночи»);
   * `sayings` — словечки («Хороший вопрос!»): хроника их цитирует; `outings` — куда выбирается в
     выходные («в библиотеку», «к букинистам»); `circle` — кружок у себя дома (`title`, дни, часы, сколько детей);
   * `habits` — `kind` из списка в схеме (reading, tv, cooking, walking, jogging, music,
     gaming, crafts, plants, phone, smoking, bench, fitness, computer), `strength` 0..1, `note`;
   * `backstory` — только если пользователь сам рассказал историю (необязательно);
   * `appearance` — кожа, `eyes` (цвет глаз), волосы (`style` + цвет; `bob_tucked` — каре за ушами),
     рост, телосложение, одежда: `style` (в т. ч. `hoodie` — толстовка, `sweater` — свитер),
     `pattern: knit` + `patternColor` — свитер с узором, `coat`, `tie` — цвет галстука,
     `variants` + `variantChance` — «иногда надевает другое» (выбирается на день);
     аксессуары (`frown` — хмурый вид, `shawl` — шаль, `glasses_big` — большие квадратные очки,
     `glasses_round` — круглые, `gray_temples` — седина на висках, `smile` — улыбка уголком рта,
     `stoop` — сутулится, `pencil_ear` — карандаш за ухом, `stubble`, `beard`, `cap` …), `hatColor`,
     `scarfColor` (длинный шарф), волосы `tousled` — взъерошенные; `street` — что меняется на улице (джинсы, обувь, кепка):
     уличное надевают в прихожей, дома — домашнее;
   * `pets` — животные (`species`: cat / dog / fish — рыбка живёт в предмете `aquarium`; `born`, `color`,
     `pattern`, `color2`, `name` если есть, `gender` кот/кошка, `tags`: «ленивый», «обжора», «спит на клавиатуре»,
     «спит на нужной книге»);
   * `contacts` — люди вне дома: родня и друзья (`kind`, `gender`, `age`, `name`,
     `visitEveryDays` — приезжают в гости, `phone` — созваниваются, `callEveryDays` — звонят раз в N дней,
     `topics` — о чём говорят, `holidays` — приезжают на праздники, `stay: short` — ненадолго,
     `tags` — каким его видят («немногословный»), `meetEveryDays` + `meetLabel` — встречи вне дома
     («в кафе играть в шахматы»), `futureResident`);
   * особенности через `traits.tags` (движок их читает): «бессонница», «любит детей» /
     «угощает детей конфетами», «знает всех жильцов», «аккуратная», «любит кофе по утрам»,
     «экспериментирует на кухне», «любит дарить подарки», «дома — только вдвоём» (к ним не ходят
     в гости), «общается онлайн в дискорде», «иногда играет ночами до 4 утра», «редко ссорятся»,
     «стоик» (неприятности задевают вдвое слабее, быстро мирится), «здоровый»/«любит спорт»
     (реже болеет), «курит … в окно», «почти не включает свет», «ночью всегда в наушниках»,
     «кошмары», «зашторивает комнату даже днём», «уволится» (говорит об этом соседям и консьержке),
     «одинок» (разговаривает с рыбкой, смотрит вслед парам), «ни с кем не в ссоре» / «никакой грубости»
     (не ссорится), «к нему подходят с вопросами» (сосед-справочник), «отвечает лекцией», «рад помочь»,
     «не умеет врать» (честно о пересоленном супе, сплетни не поддерживает), «без блокнота …» (иногда
     теряет блокнот и знакомится заново), «подолгу смотрит из окна», «пьёт чай литрами», «по воскресеньям
     печёт шарлотку» (и разносит соседям), «засиживается за книгой», «зачитавшись, забывает поесть»,
     «к политике сдержан», «шутит, что ему …» (на день рождения) и т. п. Новая черта, которую движок
     не понимает, — повод доработать движок;
   * `mannerisms` — личные манеры в анимациях, если пользователь описал жесты и привычки тела
     («сидит нога на ногу», «вечно в телефоне»): каталог `MANNERISMS` в схеме; очки, шаль, борода,
     темп по `activity` и вышивка выводятся сами. Нового жеста нет в каталоге — добавь манеру
     в `src/render/anim/personal.ts` (только добавки к общей сцене);
   * вещь, которой пользуется только один (свой компьютер, своя гитара), — `owner` у мебели в квартире;
2. **Бери черты ровно из описания пользователя.** Он описывает всё, что хочет видеть, и хочет
   знать своих жильцов досконально — поэтому в идеале ничего не добавляй. Только если без
   детали жилец не сможет жить в симуляции (нужен хронотип, график, внешность для спрайта)
   или образ явно неполон — тихо дополни в духе описания; отдельно сообщать об этом не нужно.
   `backstory` заполняй только текстом пользователя (может быть пустым) — в игре он не
   показывается.
3. **Засели в квартиру.** Свободная квартира — та, для которой нет жильцов
   (`npm run validate` печатает занятость; квартиру с `"renovation": true` заселять нельзя,
   пока пользователь не скажет, что ремонт закончен). Семью/пару — в одну квартиру.
   Если все квартиры заняты — создай квартиру на следующем этаже: дом вырастет сам.
   Если квартира новая — создай `data/apartments/apt-<этаж>-<side>.json`:
   стиль, палитра, `creaky` (скрипучий паркет — соседям снизу слышно), `balcony.items` (что на балконе), обои (для старых советских квартир — `soviet`, на кухне и в коридоре —
   `oilpaint`: крашеная панель с побелкой сверху, цвет — `wall` комнаты), пол, комнаты слева направо (сумма ширин = 16 тайлов; комната
   у лестничной клетки — прихожая `hall`: у левых квартир она справа, у правых — слева),
   мебель из `data/catalog/furniture.json` с координатой `x` в пикселях от левого края
   комнаты (высота комнаты 60 px, настенные вещи — через `elevation`). Обязательно:
   кровать(и) на всех, плита и холодильник, мойка (слот `wash` на кухне), стол или диван,
   туалет (`toilet`; в старой квартире — узкая комната `bathroom` шириной в 1 тайл, без окна).
   Интерьер — в характере жильца и подробный: не только мебель, но и мелочи
   (фотографии, полки, растения, календарь, сушилка с бельём, книги, ноутбук…). Хобби
   видно по вещам: книги → стеллаж, музыка → пианино/гитара, рукоделие → швейная машинка.
   Кратко опиши интерьер пользователю.
4. **Пропиши начальные отношения** с теми, кого упомянул пользователь, в
   `relationships` нового жильца (`with`, `kind`, `affinity` −100..100, `familiarity` 0..100,
   `note`, `dispute` — о чём давно и добродушно спорят: «как правильно заваривать чай»). Семейные связи (`spouse`, `parent`, `child`, `sibling`…) добавь и
   во второй файл с обратной ролью (parent ↔ child). Для обычных соседей обратная сторона
   выводится автоматически, но если отношение явно несимметрично — пропиши обе стороны.
5. **Запусти `npm run validate`** (и при желании `npm run sim -- --days 2`, чтобы увидеть
   жильца в хронике). Исправь ошибки, покажи итог.

После этого в браузере жилец «въедет» в уже идущий мир (сохранение дополняется новыми
жильцами, в хронике появится запись о переезде).
